# Archived baseline — truth sets with Ti/Tv ≈ 0.5

These are the baseline results (30×, 150 bp, qs 0, seed 1) produced against the ORIGINAL
truth sets, which used simuG's default `-titv_ratio 0.5` (uniformly random substitution).

**The mid-semester presentation (`docs/midsem_presentation.pptx`) quotes these numbers.**
They are kept here so every figure in that deck remains traceable.

After the mid-semester review the truth sets were regenerated with `-titv_ratio 2.0`, which
is closer to real bacterial divergence (Ti/Tv ≈ 1–2). Everything in `results/` outside this
archive refers to the Ti/Tv 2.0 truth sets. See NOTES.md, Phase 8.
